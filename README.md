# Pixel Drift 像素甩尾

像素風、俯視角的甩尾賽車遊戲。可以和電腦車比、跑賽季，也能和朋友連線對戰。這裡是電腦版的下載頁，只放安裝檔。

## 下載

到[最新版本](https://github.com/ucwwww/pixel-drift-download/releases/latest)，下載你電腦用的檔案：

- Windows：`pixel-drift-windows-setup.exe`
- Mac（Apple 晶片和 Intel 都能用）：`pixel-drift-mac.dmg`
- Linux：`pixel-drift-linux.AppImage` 或 `pixel-drift-linux.deb`

裝好之後，有新版時主畫面會出現更新按鈕。按下去程式就會自己更新、重新開啟，紀錄和設定都會留著。

## 第一次打開

程式沒有微軟或蘋果的簽章，所以第一次打開時：

- Windows 會跳出「Windows 已保護您的電腦」：按「其他資訊」，再按「仍要執行」。
- Mac 會擋下來：到「系統設定」→「隱私權與安全性」，按「強制打開」。

之後程式自己裝的更新不會再跳這些警告。

## Download

Go to the [latest release](https://github.com/ucwwww/pixel-drift-download/releases/latest) and download the file for your computer:

- Windows: `pixel-drift-windows-setup.exe`
- Mac (Apple silicon and Intel): `pixel-drift-mac.dmg`
- Linux: `pixel-drift-linux.AppImage` or `pixel-drift-linux.deb`

Once it's installed, an update button shows on the title screen whenever there's a new version. Press it and the game updates itself and reopens, keeping your records and settings.

## Opening it the first time

The program isn't signed by Microsoft or Apple, so the first time it opens:

- Windows says "Windows protected your PC": press **More info**, then **Run anyway**.
- macOS blocks it: open **System Settings → Privacy & Security** and press **Open Anyway**.

Updates the program installs itself don't bring these up again.
